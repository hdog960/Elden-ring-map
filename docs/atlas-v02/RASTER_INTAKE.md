# M1 private raster candidate intake
Run from the development repository with Node 22:
`node scripts/review-atlas-raster.mjs /private/candidate.json /private/evidence /private/new-review`
The evidence root and output must be outside repository, with an existing output parent. The report is not a deployment input. No image bytes copied. This tool handles an explicitly authorized PNG; original vector geometry remains supported by scripts/review-survey.mjs. It checks PNG header/dimension budget, not full decoding or artistic quality.
Input schema 1: layer surface/underground/shadow; gameVersion, artist, source; image {artifact,sha256,locator}; rights {basis:written-grant/original-artist-authorized,publicNoncommercial:true,offlineRedistribution:true,derivativeUse:true,attribution,reviewer,evidence:{artifact,sha256,locator}}; fit >=3 and holdout >=2 each {id,world:{x,y},map:{x,y},source,observer,method,evidence:{artifact,sha256,locator}}; maxResidual in image pixels <=1% of short edge. world is existing candidate atlas coordinate frame, measured independently from actual landmark observations, not boss projections; map is pixel location on the new source. Holdouts use separately observed artifact hashes, distinct from fit. Output per-candidate projected coverage including outside IDs, residuals, explicit nonadmission and limitations. Do not treat permissions booleans, digests or structural tests as actual human rights or geographic verification. Inspect image and verify each actual anchor/provenance before admission.
